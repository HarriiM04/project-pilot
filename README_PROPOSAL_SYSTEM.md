# 🎯 Proposal PDF Generator & Email System

**Status: ✅ Production Ready**  
**Last Built:** Successfully compiled (17.2s)  
**Dependencies:** ✅ jsPDF, ✅ Resend

## What You Get

A **complete, modular system** for generating professional proposal PDFs and sending them via branded emails. Three production-grade functions you can use anywhere in your codebase.

### 🎨 Beautiful PDFs
- Professional layout with navy headers and electric blue accents
- Automatic page breaks and page numbering
- Support for nested bullet points with bold labels
- "Project Estimates" highlight box
- Footer credit: "Generated by ProjectPilot"

### 📧 Branded Emails
- 100% compatible with Gmail, Outlook, Apple Mail
- Mobile-responsive (single-column under 600px)
- 3 stat cards (Timeline, Budget, Deliverables)
- CTA button linking to proposal
- Secondary CTA for booking calls or replying
- Agency branding + social links

### 🚀 Easy Integration
- One function call to generate PDF + send email
- Separate functions for PDF-only or email-only workflows
- HTTP endpoint for programmatic access
- Type-safe TypeScript interfaces
- Comprehensive error handling

## Quick Start (2 minutes)

### 1. Basic Send
```typescript
import { sendProposal } from '@/lib/send-proposal'

const result = await sendProposal({
  projectData: {
    project_name: "Website Redesign",
    estimated_cost: "$15,000",
    estimated_timeline: "8 weeks",
    sections: [
      {
        heading: "Phase 1: Discovery",
        text: "Understanding your needs...",
        bullets: ["User research", "Competitive analysis"]
      }
    ]
  },
  clientEmail: "client@company.com",
  clientName: "John Doe",
  agencyConfig: {
    name: "My Agency",
    email: "hello@myagency.com",
    calendlyLink: "https://calendly.com/myagency",
    primaryColor: "#2d6ef5"
  },
  proposalLink: "https://app.myagency.com/proposals/123"
})

console.log(result.success ? "✅ Sent!" : `❌ ${result.message}`)
```

### 2. Via HTTP
```bash
curl -X POST http://localhost:3000/api/proposal-mailer \
  -H "Content-Type: application/json" \
  -d '{ "projectData": {...}, "clientEmail": "...", ... }'
```

### 3. PDF Only
```typescript
import { generateProposalPDFOnly } from '@/lib/send-proposal'

const pdfBuffer = await generateProposalPDFOnly(projectData)
// Send as download or attach to email
```

## 📊 Data Structure

### ProjectData (Required)
```typescript
{
  project_name: "Website Redesign",           // string
  subtitle?: "Mobile-first approach",          // string (optional)
  estimated_cost: "$15,000",                  // string
  estimated_timeline: "8 weeks",              // string
  sections: [
    {
      heading: "Phase 1: Discovery",
      text?: "Optional description...",
      bullets?: [
        "Plain bullet",
        { label: "Bold Label", text: "Description" }
      ]
    }
  ]
}
```

### AgencyConfig (Required)
```typescript
{
  name: "My Agency",                          // string
  email: "hello@myagency.com",               // string
  calendlyLink: "https://calendly.com/...",  // string
  primaryColor: "#2d6ef5",                   // string (hex color)
  logo?: "data:image/png;base64,..."         // optional base64
}
```

## 🎨 Customization

### Change PDF Colors
Edit `lib/proposal-pdf-generator.ts` around line 40:
```typescript
const navyColor = [26, 35, 64]    // Navy
const blueColor = [45, 110, 245]  // Electric blue
```

### Change Email Colors
Edit `lib/proposal-email-template.ts`:
```html
<table style="background-color: {{PRIMARY_COLOR}}">
```

### Add New Email Variables
1. Add to `EmailTemplateVariables` interface
2. Add `{{NEW_VAR}}` to HTML template
3. Add to rendering logic in `renderEmailTemplate()`

## 🚨 Error Handling

All functions return structured results:

```typescript
{
  success: boolean,           // true/false
  message: string,            // Always present
  emailId?: string,           // On success
  error?: string              // Error code if failed
}
```

Error codes:
- `INVALID_INPUT` — Missing required fields
- `CONFIG_ERROR` — Missing environment variables
- `SEND_FAILED` — Resend API error
- `SERVER_ERROR` — Unexpected exception
